# LAMP Server

[To learn more about the LAMP Platform, visit our documentation.](https://docs.lamp.digital/)

## Release Branch: v2 (Basic Auth)

This is the `release/v2` branch — the stable basic-auth version of the LAMP Server. It has no external LAMP dependencies.

This branch receives critical and security fixes only. For the latest features (session auth, OAuth, 2FA, API keys), see the `master` branch or `release/v3` when available.
